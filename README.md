The One-Line Excuse an Agent Gives Its Human: one line (125 characters) — an agent that delegated a deadline down a chain of subagents, none of which has started yet.

## Run it

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (one line, 125 characters, pure Python standard library, deterministic — same bytes every run).
